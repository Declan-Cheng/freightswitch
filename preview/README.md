## Run locally

From the repository root:

```sh
python3 -m http.server 8910 --bind 127.0.0.1 --directory preview/dist
```

Open <http://127.0.0.1:8910/>. Serve `dist/` as the web root because its asset paths are root-relative. A modern browser with Web Crypto and local storage is required. No account, API key, package installation or model call is needed.

## What runs

- Agreement outputs captured from all 20 prefixes of the authored synthetic fixture, plus its ambiguous-time example.
- Offline scripted mock outputs and two source-bound authored review examples generated by the frozen public Python code.
- A separately tested browser adapter for human assessments, explicit accept acknowledgments, stale-source rejection, browser-local audit history and evidence export.
- Original `advisory.js` and `style.css` copied from the frozen core; `app.js` changes only the runtime label. The preview's disclosure layer hides the legacy free-form review workspace and recorded-model inspection; those features remain available in the separate Python app.

## Important limits

- No live inference, model-generated responses, API keys, real customer data, carrier connection or dispatch. Historical benchmark figures remain visible but are not new or improved results.
- Agreement states are captured outputs, **not dynamically re-evaluated JavaScript results**. Arbitrary shipment evaluation and arbitrary new model proposals are unavailable. Use the Python app for its broader local workflow.
- Human review records use this browser's local storage, not SQLite or a remote database. They survive reload in the same browser but not deletion of site data, and are not shared across devices. A browser owner can modify them; this is not a tamper-proof audit system.
- Source hashes establish consistency, not identity. Neither model suggestions nor local human interpretations authenticate a counterparty, establish legal acceptance or authorize operations. Human assessments never change the separate authored shipment agreement.
- `/api/*` calls are intercepted inside this page by `demo-api.js`; they are **not public server API endpoints**.
- Browser JSON parsing uses `JSON.parse`; raw-body/duplicate-key rejection parity with the Python server is not claimed. The included differential cases cover the bounded object-level contract, not every possible request.
- No private evaluation inputs, gold labels, private audits, account metadata or deployment credentials are included.

## Reproduce the checks

From the repository root, with Python and Node installed:

```sh
node preview/tests/preview_contract.js
python3 preview/tests/reference_contract.py . /tmp/freightswitch-reference-cases.json
```

The Node suite passes **86 checks**, including **43 differential request cases** against stored Python outcomes. Fresh regeneration of those 43 outcomes was checked against the frozen Python reference and matched as JSON values; dictionary key order can differ. These checks cover captured scenes, persistence, idempotency, stale-source rejection, blocked live routes and export provenance. They are not browser visual tests or model-accuracy measurements.

Prior actual internal-preview browser QA reported **23 UI checks**, including CSS viewport frames at 320, 390 and 1280 pixels and real export downloads; those frames are not native-mobile-device tests. Separate anonymous public-demo verification exercised the authored v6 human-interpretation workflow, reload persistence and export. See `verification-summary.json` for scope. This does not establish production readiness or future availability.

## Regenerate a new snapshot without overwriting this release

The generator refuses a reference source digest other than the frozen one. It uses real offline Python fixture outputs, never evaluation/gold files or a model call. Run it in a disposable copy:

```sh
tmp=$(mktemp -d)
cp -R preview "$tmp/preview"
python3 "$tmp/preview/build_preview.py" "$PWD"
```

A regeneration creates fresh local UUIDs/timestamps and therefore a **different preview digest** even when scenario semantics match. The committed `capture.json`, `dist/` and manifest are the exact published snapshot; do not overwrite them and still claim the old preview identity. Source digests identify files/snapshots, not process attestation.
